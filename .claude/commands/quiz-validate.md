questions.js의 문항을 CLAUDE.md의 "문항 작성 규칙"으로 점검한다.

## 지켜야 할 것

- 점검만 한다. questions.js를 비롯해 어떤 파일도 만들거나 고치거나 지우지 않는다.
  - Edit, Write, NotebookEdit 도구와 파일을 바꾸는 셸 명령을 쓰지 않는다.
  - 고칠 방법은 표의 "고칠 방향" 칸에 글로만 적는다.
- 규칙의 정본은 CLAUDE.md다. 아래 "규칙별 판정 기준"보다 먼저 CLAUDE.md를 읽고, 둘이 다르면 CLAUDE.md를 따른다.

## 점검 범위

- `$ARGUMENTS`가 비어 있으면 questions.js의 모든 문항을 점검한다.
- `$ARGUMENTS`에 문항 id(예: `kh-03`)나 카테고리(예: `세계지리`)가 있으면 그 문항만 점검한다.

## 순서

1. CLAUDE.md의 "문항 작성 규칙" 10개와 PRD.md 6.1항(데이터 형식), 6.2항(출처 표기)을 읽는다.
2. questions.js 전체를 읽는다.
3. 문항마다 규칙 1~10과 PRD 6.2항을 하나씩 대조한다.
4. 아래 "출력 형식"대로 보고한다.

## 규칙별 판정 기준

| 규칙 | 어긴 것으로 보는 경우 |
|---|---|
| 1 | `answer`가 `choices`에 정확히 1번 나오지 않음. 또는 다른 보기도 문제 문장의 조건으로 정답이 될 수 있음 |
| 2 | "가장", "최대", "최초" 같은 최상급 표현이 있는데 문제 문장에 기준이나 시점이 없음 |
| 3 | `choices`가 4개가 아니거나, 같은 보기가 2번 이상 나옴 |
| 4 | 해설이나 문제에 쓴 값이 출처와 다르거나, 출처마다 값이 다르다고 알려진 값을 씀 |
| 5 | 문제 문장에 비문, 어색한 조사, 번역투가 있음 |
| 6 | 해설이 `answer`와 다른 보기를 정답처럼 설명하거나, 해설 내용이 정답과 맞지 않음 |
| 7 | 오답이 정답과 다른 유형임(예: 인물을 묻는데 오답에 지명이 섞임). 또는 누가 봐도 답이 아닌 보기가 있음 |
| 8 | 한 보기만 유난히 길거나 짧음(대략 2배 넘게 차이). 또는 단위, 접미사, 표기 형식이 한 보기만 다름 |
| 9 | 문제 문장이 "~이 아닌 것은?", "~하지 않은 것은?" 같은 부정문임 |
| 10 | "모두 맞음", "위의 어느 것도 아님" 같은 보기가 있음 |
| PRD 6.2 | `source`에 자료명, URL, 확인한 날짜 중 하나라도 빠졌거나 `explanation`이 비어 있음 |

- 규칙 4는 파일만으로 판정할 수 없다. 이 명령어는 웹 대조를 하지 않으므로, 내가 알고 있는 사실과 분명히 어긋나는 값만 "규칙 4 의심"으로 적고, 그 밖의 문항은 규칙 4를 확인하지 못한 것으로 둔다.
- 판정이 애매하면 어긴 것으로 단정하지 말고 "의심"으로 표시한다.

## 출력 형식

1. 첫 줄에 점검 범위와 결과를 한 문장으로 적는다.
   - 형식: "전체 N문항 중 M문항이 규칙에 어긋남." 범위를 좁혔으면 "전체" 대신 점검한 id나 카테고리를 적는다(예: "세계지리 N문항 중 M문항이 규칙에 어긋남.").
   - N은 이번에 점검한 문항 수로, "순서" 2번에서 읽은 questions.js에서 직접 센다. M은 그 가운데 아래 표에 올린 문항 수다.
2. 어긋난 문항을 아래 표로 보여 준다. 한 문항이 규칙 여러 개를 어기면 한 행에 규칙 번호를 쉼표로 이어 적는다.

| id | 문제 문장 | 어긴 규칙 | 근거 | 고칠 방향 |
|---|---|---|---|---|
| (예시) xx-01 | 세계에서 가장 긴 강은? | 1, 2 | 최상급인데 기준과 시점이 없고, 측정 기준에 따라 나일강과 아마존강이 모두 답이 될 수 있음 | 기준과 시점을 넣거나 다른 사실로 바꿈 |
| (예시) xx-02 | 다음 중 포유류가 아닌 것은? | 9 | 부정문으로 물음 | 긍정문으로 바꿈 |

   - "어긴 규칙" 칸에는 CLAUDE.md의 규칙 번호(1~10)나 "PRD 6.2"만 적는다.
   - "근거" 칸에는 해당 문항의 어느 부분이 왜 어긋나는지 한 줄로 적는다.
   - 표는 id 순서로 정렬한다.
3. 어긋난 문항이 없으면 표 대신 "규칙에 어긋난 문항 없음."이라고 적는다.
4. 마지막에 "확인하지 못한 것"을 적는다. 최소한 규칙 4(웹 출처 대조)를 하지 않았다는 점을 밝힌다.
